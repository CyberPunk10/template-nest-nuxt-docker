# .husky/

Git-хуки проекта.

```
.husky/
├── pre-commit          запускает lint-staged перед коммитом
└── _/                  служебные файлы husky, в git не попадают
```

## Хук перед коммитом

`.husky/pre-commit` вызывает `lint-staged` — линтер проходит **только по изменённым файлам**, а не по всему репозиторию. Хуки ставятся автоматически: в корневом `package.json` есть скрипт `prepare: husky`, который pnpm выполняет после установки зависимостей.

Сам хук — одна строка:

```bash
pnpm lint-staged
```

Что именно запускать на файлах, решает `lint-staged.config.js` в корне: для `js/mjs/ts/tsx/vue` — `eslint --fix`.

## Как отключить проверку разово

```bash
git commit --no-verify -m "..."
```

Флаг пропускает хуки целиком. Пользоваться редко: линтер на коммите — последняя проверка перед тем, как код уедет в общую ветку.
