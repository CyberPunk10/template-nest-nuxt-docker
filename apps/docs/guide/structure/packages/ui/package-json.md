# package.json

```json
{
  "name": "@repo/ui",
  "private": true,
  "main": "./src/index.ts",
  "types": "./src/index.ts",
  "scripts": {
    "type-check": "vue-tsc --noEmit"
  }
}
```

| Скрипт       | Команда            | Что делает                        |
| ------------ | ------------------ | --------------------------------- |
| `type-check` | `vue-tsc --noEmit` | Проверка типов, включая `.vue`-файлы |

Здесь `vue-tsc`, а не `tsc`: обычный компилятор не умеет разбирать однофайловые компоненты.

Сборки нет — Vite обрабатывает исходники напрямую. `private: true` означает, что пакет не публикуется и подключается через `workspace:*`.
