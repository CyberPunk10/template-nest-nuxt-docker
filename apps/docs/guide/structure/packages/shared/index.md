# packages/shared

Общие типы и переводы. Единственный пакет, который используют **оба** приложения.

```
packages/shared/
├── src/
│   ├── i18n/           переводы: ru, en, th
│   └── index.ts        типы (DTO) и точка экспорта
├── package.json
└── tsconfig.json       компилируется в dist/ (ESM)
```

## Зачем компилируется

Backend работает в CommonJS, frontend — в ESM через Rollup. Отдавать им исходники нельзя: каждый ожидает свой формат модулей. Скомпилированный ESM-выход в `dist/` подходит обоим.

Поэтому в `tsconfig.base.json` алиас `@repo/shared` указывает на `dist/index.d.ts` — на **скомпилированные** типы, а не на исходник.

## Что здесь держать

Всё, что должно совпадать на клиенте и сервере: формы запросов и ответов, перечисления статусов, тексты интерфейса. Если тип нужен только одной стороне — ему место в самом приложении, а не здесь.

Манифест пакета — [package.json](/guide/structure/packages/shared/package-json).
